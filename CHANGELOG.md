# Changelog

All notable changes documented here.

## [0.1.0] - 2026-10-05

### Added

- **custom-ai-workflow skill** — Automatically adopts the Universal AI Engineering Skill into any repository
  - Discovery protocol: detects languages, frameworks, tooling, conventions, patterns
  - Analysis framework: classifies project type, maturity, tech stack, team context
  - Question library: ~20 clarifying questions for ambiguous choices
  - Template system: parametrized templates that adapt to any tech stack
  - Scenarios: detailed walkthroughs for TypeScript, Go, Python projects
  - Generates: `.ai/SKILL.md`, `.ai/AGENTS.md`, `rules/`, `references/` customized to the repo
