# Changelog

All notable changes to this standard are documented here.

## [0.1.0] - 2026-10-05

### Added

- Initial specification-first workflow standard.
- Adaptive L0–L4 task classification.
- Repository discovery, context hierarchy, sanity, architecture, security, Git, testing, and Definition of Done guidance.
- Feature, bugfix, refactor, investigation, migration, and code-review workflows.
- Optional planner, implementer, reviewer, tester, and investigator contracts.
- Debugging, testing, refactoring, API design, database, and security-review skills.
- Minimal, standard, and monorepo starter profiles.
- Conservative adapters for common AI coding tools.
- Decision-record template, configuration schema, and adoption examples.
