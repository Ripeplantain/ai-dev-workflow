# Tool Adapters

Adapters are integration guidance, not alternate standards. A tool adapter should make the tool:

1. read the core standard;
2. load repository and path-specific instructions;
3. classify the task;
4. load the relevant workflow and skills;
5. execute with architecture and Git discipline;
6. verify, review, clean, and report.

The exact file name, front matter, command, or rules mechanism belongs to the tool and must be verified against that tool's current documentation. When an exact format is uncertain, use the tool's supported instruction entry point and point to the canonical documents rather than inventing configuration.
