# Optional Agents

Agents are execution contracts, not required architecture. A tool without subagents can execute the same responsibilities sequentially in one context.

Recommended handoff format:

```text
Status: complete | needs-input | blocked
Scope: files/modules inspected or changed
Findings: confirmed facts and risks
Plan/changes: concise summary
Verification: exact commands and outcomes
Open items: unresolved questions or follow-ups
```
