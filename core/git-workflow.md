# Git Discipline

- Inspect status before editing and preserve pre-existing user changes.
- Modify only files related to the request.
- Respect `.gitignore` and understand generated files before adding them.
- Keep a cohesive, reviewable diff.
- Inspect the final diff and status before reporting.
- Never commit secrets.
- Avoid repository-wide formatting for localized work.
- Do not rewrite history, force-push, reset, clean, or delete work unless explicitly requested.
- Do not overwrite a user's uncommitted changes.

The AI may suggest commits, but commit policy belongs to the repository and the user. If a check cannot run, record the limitation rather than hiding it.
