# Workflows

Workflows are task-specific compositions of the universal lifecycle. Load the relevant workflow after discovery and classification; do not apply every workflow to every task.

Each workflow inherits:

- `core/principles.md`
- `core/context.md`
- `core/repository-discovery.md`
- `core/repo-sanity.md`
- `core/architecture.md`
- `core/testing.md`
- `core/security.md`
- `core/git-workflow.md`
- `core/definition-of-done.md`
