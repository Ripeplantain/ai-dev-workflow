# Bug Fixing

Use for incorrect behavior, regressions, or production defects.

1. **Reproduce or bound the failure** with a failing test, trace, log, or precise evidence.
2. **Investigate** the smallest relevant execution path and recent changes.
3. **Classify** severity, user impact, security implications, and regression risk.
4. **Plan** a focused fix and a regression check. Avoid unrelated cleanup.
5. **Implement** the minimal root-cause correction rather than masking symptoms.
6. **Verify** the regression, affected checks, and edge cases.
7. **Review and report** cause, fix, evidence, remaining uncertainty, and any follow-up.

If reproduction is unavailable, state what was inferred and what evidence would increase confidence.
