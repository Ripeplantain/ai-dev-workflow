# AI Engineering Workflow — minimal profile

AI should adapt to this repository. Before changing code:

1. Read this file and any more-specific `AGENTS.md`.
2. Inspect nearby code and existing commands; do not assume architecture or tooling.
3. Classify the task: trivial, small, standard, significant, or critical.
4. Make the smallest correct change and avoid unrelated files, duplicate utilities, and speculative dependencies.
5. Run the narrowest relevant verification and report exact commands and limitations.
6. Review the diff for secrets, debug artifacts, user changes, and unintended scope.

For significant or critical work, use the full standard from the upstream `ai-dev-workflow` repository and document risks and decisions.
